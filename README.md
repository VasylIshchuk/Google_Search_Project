# Google Search Frontend Clone

## 🎯 Project Goal

This project replicates the frontend interface of Google Search using only HTML and CSS. It allows users to perform real Google searches, including web search, image search, and advanced search, by sending proper GET requests through HTML forms.

## 📄 Description

The website consists of three main pages:

- **google_search.html** – Standard Google Search page
- **image_search.html** – Google Image Search page
- **advanced_search.html** – Google Advanced Search page

Each form mimics Google’s actual search functionality by submitting user input to Google’s endpoints via GET parameters.

## 🔍 Features

- Search input that redirects to Google search results using the `q` parameter.
- A separate page for image search using Google Images.
- An advanced search page that supports:
  - All these words
  - This exact word or phrase
  - Any of these words
  - None of these words
- CSS styling to resemble the original Google look.
- Navigation links in the top-right corner of each page to switch between modes.
